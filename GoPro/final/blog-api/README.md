# REST API для блога на Go (Blog-API)

Промышленное REST API для блога с поддержкой авторизации (JWT), постов, комментариев, структурированного логирования, автоматических миграций и встроенной защиты от DDoS. Построено на архитектуре разделения слоев (Handler -> Service -> Repository -> Database).

## 🚀 Основные возможности

- **Аутентификация**: Регистрация и вход пользователей с генерацией безопасных JWT-токенов.
- **Управление публикациями**: Создание, чтение, пагинация, обновление и удаление постов (удаление и редактирование доступно только автору).
- **Система комментариев**: Написание комментариев к публикациям, обновление и удаление собственных комментариев.
- **Инфраструктурные Middleware**:
  - `Recovery` — автоматический перехват паник для предотвращения падения сервера.
  - `RequestID` — генерация сквозного ID для трассировки цепочки логов.
  - `CORS` — гибкая настройка заголовков для работы с фронтендом.
  - `RateLimiter` — защита API от DDoS и брутфорса (Token Bucket на `sync.Map`).
  - `Logger` — детальные логи запросов с подсчетом байт ответа и времени обработки.
- **База данных**: Автоматические транзакционные миграции схемы данных при старте.

## 🛠 Технологический стек

- **Язык**: Go (Golang) 1.20+
- **HTTP Роутер**: [go-chi/v5](https://github.com/go-chi/chi/v5)

- **Драйвер БД**: [lib/pq](https://github.com/lib/pq)
- **Конфигурация**: Environment Variables через [godotenv](https://github.com/joho/godotenv)
- **Контейнеризация**: Docker & Docker Compose

## 💻 Быстрый старт

### 1. Подготовка конфигурации
Создайте файл `.env` в корневой папке проекта:

```env
# Настройки сервера Go
SERVER_PORT=8080
SERVER_HOST=0.0.0.0

# Настройки PostgreSQL для Docker и Go
DB_HOST=127.0.0.1
DB_PORT=5432
DB_USER=bloguser
DB_PASSWORD=blogpassword
DB_NAME=blogdb
DB_SSL_MODE=disable

# Безопасность (JWT)
JWT_SECRET=super-secure-random-secret-key-32-chars
JWT_EXPIRY_HOURS=24
```

### 2. Запуск инфраструктуры (PostgreSQL в Docker)
Сбросьте старые данные и поднимите контейнер с базой данных:
```bash
docker compose down -v
docker compose up -d
```

### 3. Запуск API-сервера
Синхронизируйте модули Go и запустите компиляцию приложения:
```bash
go mod tidy
go run ./cmd/api/
```
При успешном старте вы увидите логи:
```text
Successfully connected to the database
Database migrations applied successfully
Starting HTTP server on 0.0.0.0:8080
```

## 🎯 Спецификация API (Основные эндпоинты)

### Публичные эндпоинты
- `POST /api/register` — Регистрация нового аккаунта.
- `POST /api/login` — Аутентификация (возвращает JWT-токен).
- `GET /api/posts` — Список постов (поддерживает Query-параметры `limit` и `offset`).
- `GET /api/posts/{id}` — Получение поста по его уникальному ID.
- `GET /api/posts/{id}/comments` — Список комментариев к конкретному посту.
- `GET /api/health` — Сервисный эндпоинт проверки работоспособности.

### Защищенные эндпоинты (Требуют заголовок `Authorization: Bearer <token>`)
- `POST /api/posts` — Создание новой публикации.
- `PUT /api/posts/{id}` — Обновление текста/заголовка поста (доступно только автору).
- `DELETE /api/posts/{id}` — Удаление публикации (доступно только автору).
- `POST /api/posts/{id}/comments` — Написание комментария к выбранному посту.
- `PUT /api/comments/{id}` — Редактирование комментария (доступно только автору).
- `DELETE /api/comments/{id}` — Удаление комментария (доступно только автору).
