# URL Analyzer (Анализатор производительности веб-серверов)

Консольное приложение на Go, которое имитирует отправку HTTP-запросов к списку URL-адресов, замеряет время их выполнения и выводит агрегированную статистику.

Проект разработан с использованием конкурентных паттернов Go для эффективной параллельной обработки данных.

## 🛠 Технологии и Паттерны
* **Язык программирования:** Go (Golang)
* **Worker Pool:** Ограничивает количество одновременно работающих горутин для контроля нагрузки.
* **Fan-out:** Распределяет входящие задачи (URL) из единого канала между несколькими независимыми воркерами.
* **Fan-in:** Собирает результаты обработки из горутин-воркеров обратно в один результирующий поток данных.
* **Синхронизация:** Использование `sync.WaitGroup` и каналов гарантирует безопасную работу с памятью без гонок данных (data races).

## 📁 Структура проекта
Проект организован по общепринятому стандарту **Standard Go Project Layout**:
```text
url-analyzer/
├── cmd/
│   └── analyzer/
│       └── main.go       # Точка входа: инициализация данных и вывод отчетов
├── internal/
│   └── pool/
│       ├── job.go        # Описание структур данных (Job, Result)
│       └── worker.go     # Логика работы Worker Pool, Fan-out и Fan-in
├── go.mod                # Управление модулями и зависимостями
└── README.md             # Документация проекта, инструкции по запуску и описания
```

## 🚀 Быстрый запуск

### 1. Системные требования
Убедитесь, что у вас установлен Go (версии 1.18 или выше). Проверить установку можно командой:
```bash
go version
```

### 2. Инициализация проекта (если делается впервые)
Если вы создаете проект с нуля в пустой папке:
```bash
go mod init url-analyzer
```

### 3. Запуск приложения
Запустите проект напрямую из корневой директории без предварительной сборки:
```bash
go run cmd/analyzer/main.go
```

### 4. Компиляция и запуск бинарного файла
Если вы хотите собрать готовый исполняемый файл:
```bash
# Сборка приложения в папку bin
go build -o bin/analyzer cmd/analyzer/main.go

# Запуск скомпилированного файла (для Linux/macOS)
./bin/analyzer

# Запуск скомпилированного файла (для Windows)
.\bin\analyzer.exe
```
