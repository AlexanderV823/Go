# URL Shortener (Сервис сокращения URL-адресов)

Простой и быстрый HTTP-сервис на Go для сокращения длинных URL-адресов и перенаправления (редиректа) пользователей по коротким идентификаторам. Проект полностью покрыт Unit-тестами и интеграционными тестами HTTP-обработчиков.

## 🛠️ Стек технологий
* **Go** (версия ≥ 1.18)
* Встроенный HTTP-сервер (`net/http`)
* Потокобезопасное хранилище в памяти (`sync.RWMutex`, `map`)
* Тестирование с помощью стандартного пакета `testing` и `net/http/httptest`

## 📁 Структура проекта
* `main.go` — Маршрутизация и запуск HTTP-сервера.
* `shortener.go` — Бизнес-логика (валидация URL, генерация коротких ID, работа с мапой).
* `shortener_test.go` — Unit-тесты для бизнес-логики (Table-driven).
* `handlers_test.go` — Тесты для HTTP-обработчиков (эндпоинтов POST и GET).

## 🚀 Инструкция по запуску

### Запуск сервера
Сервер по умолчанию запускается на порту `:8080`:
```bash
go run main.go shortener.go
```

### Запуск тестов и проверка покрытия (>80%)
Выполнить тесты в подробном (verbose) режиме:
```bash
go test -v
```

Запустить тесты, собрать покрытие и сразу открыть интерактивный HTML-отчет в браузере:
```bash
go test -coverprofile=coverage.out && go tool cover -func=coverage.out && go tool cover -html=coverage.out
```

## 📡 Спецификация API

### 1. Сокращение URL (POST `/shorten`)
Принимает длинный URL в формате JSON, валидирует его (схема должна быть `http` или `https`) и возвращает уникальный короткий ID (длиной от 6 до 8 символов).

* **Пример запроса через curl:**
  ```bash
  curl -X POST http://localhost:8080/shorten \
       -H "Content-Type: application/json" \
       -d '{"url": "https://google.com"}'
  ```
* **Пример ответа (200 OK):**
  ```json
  {
    "short_url": "4a_RzA",
    "original_url": "https://google.com"
  }
  ```

### 2. Редирект на оригинальный URL (GET `/{short_url}`)
Принимает короткий идентификатор в пути запроса. Возвращает статус `302 Found` с перенаправлением в заголовке `Location`. Если ID не найден — возвращает `404 Not Found`.

* **Пример запроса через curl:**
  ```bash
  curl -I http://localhost:8080/4a_RzA
  ```
