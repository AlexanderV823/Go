# Проектная работа «Разработка конкурентного сервиса»

1. Запуск приложения возможен со следующими флагами:
   	-workers - количество воркеров для обработки, значение по умолчанию 3;
	-status - минимальный статус-код для фильтрации, значение по умолчанию 400;
	-top - количество топ IP-адресов для вывода, значение по умолчанию 3;
	-logfile - путь к файлу лога, значение по умолчанию testdata/log.csv.
    Пример запуска программы: go run . -workers=5 -status=500 -top=5 -logfile=mylog.csv
2. Выход из приложения возможен вызовом Ctrl+C или по передаче SIGTERM.
3. Запуск с флагом -help выводит справку в консоль.
4. Для запуска теста необходимо выполнить команду go test -race.
