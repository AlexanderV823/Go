# Проектная работа «Мини-приложение для управления задачами на Go»

Консольное приложение поддерживает следующие команды:
1. [x] add → Добавить задачу (флаг --desc)  
   Пример вызова: add -desc="Купить продукты"  
   При добавлении новой задачи генерируется и сообщается пользователю ее уникальный номер (id) в диапазоне от 1 до 250.  
2. [x] list → Вывести задачи (флаг --filter=all/done/pending, значение по умолчанию all)
   Пример вызова: list --filter=pending  
   Последовательно выводит все задачи, согласно указанному фильтру.
3. [x] complete → Отметить задачу выполненной (флаг --id, значение по умолчанию 0)
   Пример вызова: complete --id=2  
   Осуществляется поиск по всему списку загруженных и созданных задач. Задаче с найденным id присваивается отметка о выполнении. Если задачи с таким id нет, выводится сообщение пользователю.
4. [x] delete → Удалить задачу (флаг --id, значение по умолчанию 0)
   Пример вызова: delete --id=3  
   Осуществляется поиск по всему списку загруженных и созданных задач. Задача с указанным id удаляется из списка. Если задачи с таким id нет, выводится сообщение пользователю.
5. [x] export → Экспорт в CSV/JSON (флаги --format, значение по умолчанию json, --out, значение по умолчанию tasks.json)
   Пример вызова: export --format=csv --out=Tasks
   Во флаге --format должен быть указан один из двух допустимых форматов сохранения: JSON или CSV. Формат по умолчанию: JSON. Во флаге --out указывается имя сохраняемого файла без расширения. Расширение указывается автоматически, в зависимости от выбраннного формата. Файл будет сохранен в папке MyTasks в домашнем каталоге пользователя.
6. [x] load → Импорт из CSV/JSON (флаг --file, значение по умолчанию tasks.json)
   Пример вызова: load --file=mytasks.csv  
   По умолчанию при запуске программы загружается список задач из файла tasks.json, расположенного в папке MyTasks, находящейся в домашнем каталоге текущего пользователя. Если такого файла или папки не существует, то они будут созданы. Файл для загрузки необходимо предварительно переместить в папку MyTasks.
