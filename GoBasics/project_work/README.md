# Проектная работа «Мини-приложение для управления задачами на Go»

Консольное приложение поддерживает следующие команды:
1. [] add → Добавить задачу (флаг --desc)
2. [] list → Вывести задачи (флаг --filter=all/done/pending, значение по умолчанию all)
3. [] complete → Отметить задачу выполненной (флаг --id, значение по умолчанию 0)
4. [] delete → Удалить задачу (флаг --id, значение по умолчанию 0)
5. [] export → Экспорт в CSV/JSON (флаги --format, значение по умолчанию json, --out, значение по умолчанию tasks.json)
6. [] load → Импорт из CSV/JSON (флаг --file, значение по умолчанию tasks.json)
   Пример вызова: load --file=mytasks.csv
   По умолчанию при запуске программы загружается список задач из файла tasks.json,
   расположенного в папке MyTasks, находящейся в домашнем каталоге текущего пользователя.
   Если такого файла или папки не существует, то они будут созданы.
   Файл для загрузки необходимо предварительно переместить в папку MyTasks.
