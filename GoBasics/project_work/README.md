# Проектная работа «Мини-приложение для управления задачами на Go»

Консольное приложение поддерживает следующие команды:
- [] add → Добавить задачу (флаг --desc)
- [] list → Вывести задачи (флаг --filter=all/done/pending)
- [] complete → Отметить задачу выполненной (флаг --id)
- [] delete → Удалить задачу (флаг --id)
- [] export → Экспорт в CSV/JSON (флаги --format, --out)
- [] load → Импорт из CSV/JSON (флаг --file)
